# GOOFY — домашний каталог мультсериалов

Откройте **index.html двойным щелчком** в браузере. Установка, Node.js, сервер, интернет, платные API, подписка и база данных для работы не нужны.

Вся программа — обычные файлы в этой папке. Сохраните их рядом друг с другом. Исходная CRM-страница сохранена в `crm-original.html`.

## Первый просмотр

1. Откройте каталог, сериал и нужную серию.
2. Нажмите **«Видео / озвучка»** или **«Выбрать видео»**.
3. Выберите своё видео и укажите озвучку. Нажмите «Сохранить».
4. Нажмите большую кнопку ▶ на экране телевизора.

Видео мультсериалов в комплект не входят. В стартовом каталоге есть четыре сериала и по три начальные карточки. Это начальная библиотека, а не полный проверенный каталог всех сезонов. Даты и длительности, которых нет в данных, показываются как неизвестные.

Браузер воспроизводит только поддерживаемые им форматы и кодеки. При ошибке попробуйте свой MP4 с H.264/AAC или WebM. Приложение не перекодирует видео.

## Чтобы не выбирать файл каждый раз

Поместите видео в папку `media` рядом с `index.html`, например:

```
goofy/
  index.html
  app.js
  core.js
  player.js
  seed.js
  styles.css
  media/
    futurama/
      S01E01.mp4
```

На странице серии нажмите **«Путь к файлу»** и укажите `media/futurama/S01E01.mp4`. Используйте `/` и относительный путь, без `C:`, `..`, URL и начального `/`. Переносите папку сайта целиком вместе с `media`.

Обычный выбор файла через диалог даёт доступ к нему на время открытой страницы. После перезапуска выберите тот же файл через «Подключить файл» в сведениях об источниках или снова подключите его папку. История и позиция при этом сохраняются. Если файл изменился, программа предложит добавить отдельную версию — её монтаж может отличаться.

## Импорт папки с видео

Кнопка **«Мои видео»** на главной или **«Папка с видео»** в библиотеке сканирует только выбранную вами папку. Видео не копируются и никуда не отправляются.

Рекомендуемые имена:

```
Futurama.S01E01 - Studio A.mp4
South Park.S05E03 - Studio B.webm
Симпсоны/S02E01 - Моя озвучка.mp4
```

Код `SxxExx` определяет сезон и серию, остаток имени после кода — название озвучки. Сериал определяется по названию файла или папки. Перед импортом покажется список: проверьте выбор сериала для каждого файла. Неопознанные файлы можно пропустить и добавить вручную. Сезон `S00` предназначен для спецвыпусков.

Повторное подключение той же папки восстанавливает доступ к ранее выбранным файлам. Повторный импорт каталога не создаёт повторных серий, источников и уведомлений. Программа не следит за папкой в фоне: для новых файлов нажмите импорт повторно.

## Просмотр

- Пауза, шкала времени, перемотка ±10 секунд, громкость, скорость.
- Полный экран и «Картинка в картинке» показываются при наличии соответствующего API браузера.
- На узком экране скорость и ползунок громкости скрыты; звук можно выключить кнопкой и регулировать средствами устройства.
- Переключатель рамки телевизора сохраняет тот же видеоэлемент и позицию.
- В фокусе самого плеера: пробел — пауза, стрелки — перемотка, M — звук, F — полный экран. Эти сочетания не перехватывают поля и кнопки.
- Позиция записывается каждые 10 секунд события воспроизведения, при паузе, скрытии страницы и выходе, когда браузер позволяет обработать событие.
- Завершённая серия отмечается просмотренной. Ручная отметка доступна всегда.
- Автопереход выключен изначально. В настройках его можно включить; отсчёт длится 10 секунд и отменяется кнопкой. Переход выполняется только при доступном локальном источнике с той же озвучкой.
- Для смены монтажа предлагается выбор: продолжить с текущего времени или начать сначала. Заполняйте одинаковую «группу монтажа» только для проверенных, совпадающих временных шкал.
- Субтитры подключаются файлом `.vtt` на время страницы. SRT нужно предварительно преобразовать в WebVTT самостоятельно. Качество не выбирается: локальный файл воспроизводится в исходном качестве.

## Сохранение и перенос

Программа использует **localStorage** для текущих настроек и истории в этом браузере. Это локальный браузерный кэш, а не отдельный JSON на диске. Его доступность для `file://` зависит от браузера; перенос или переименование папки может изменить область хранения. Очистка данных браузера удаляет кэш.

Для постоянной копии откройте **Настройки → Сохранить резервную копию**. Скачивается обычный JSON: каталог, озвучки, источники, коллекция, прогресс, настройки, уведомления, журнал и спорные сопоставления. Видео и временные разрешения доступа к файлам в него не включаются.

На другом компьютере перенесите папку с сайтом, видео и JSON. Откройте сайт → Настройки → Открыть JSON:

- **Объединить каталог** — добавляет записи, сохраняет текущую коллекцию и историю. Защищённые ручные правки не перезаписываются.
- **Восстановить всё** — заменяет библиотеку, историю и настройки данными копии. Предыдущая библиотека сначала передаётся браузеру для скачивания резервной копией; завершение загрузки контролируйте в браузере.

Браузер не может без вашего действия перезаписывать произвольные файлы. Поэтому отдельную JSON-копию нужно скачивать вручную. При недоступном localStorage сайт покажет предупреждение.

## Управление библиотекой

Ссылка **«Управление библиотекой»** находится внизу каждой страницы.

Здесь можно добавлять и редактировать сериалы, сезоны (номером в серии), серии и спецвыпуски, импортировать папку или JSON, объединять ошибочно разнесённые записи, смотреть журнал ошибок и список спорных сопоставлений. Озвучки, локальные источники и группы монтажа редактируются со страницы серии в разделе «О серии, источниках и управлении».

При ручной правке серии включена защита метаданных от импортов. Ошибка импорта не удаляет существующий каталог. Конфликт ID и номера откладывается для проверки: исправьте исходный JSON и импортируйте снова. Отдельной внешней/внутренней нумерации поставщиков эта локальная версия не ведёт.

Формат JSON показан в `example-catalog.json`. Поле `schemaVersion` равно `1`. ID состоят из латинских букв, цифр, `_` и `-`. Уникальны ID сериалов, ID серий, пара «сериал + сезон + номер» и ID источников внутри серии. Структура описана в `DATA_FORMAT.md`.

## Применённые изменения к техническому заданию

Ваше требование об автономных обычных файлах имеет приоритет над серверными пунктами ТЗ.

| Пункт ТЗ | Локальная реализация |
|---|---|
| Сервер, HTTPS, авторизация, роли, база | Не требуются для персонального `file://`-приложения. Редактор открыт владельцу файлов. |
| Синхронизация между устройствами | Ручной перенос JSON и видео. |
| API, фиды и обновление раз в сутки | Импорт выбранной папки и JSON по действию пользователя. |
| Внешние плееры, потоки и ссылки на площадки | Исключены. Только локальные видео; сетевые запросы блокируются политикой страницы. |
| Уведомления и подписки | Локальные события импорта, без рассылок и подписок. |
| Резервное копирование базы | Экспорт/восстановление обычного JSON. |
| Реальные серии четырёх сериалов | Предоставляются пользователем как видеофайлы. Видеоконтент не скачивался и в комплект не включён. |

Полная приёмка исходного сетевого MVP (полные каталоги, реальные поставщики и регистрация на двух устройствах) к этой локальной версии неприменима. Приёмка с вашим видео и визуальная проверка браузера ещё не выполнены — см. `VERIFICATION.md`.

## Проверки для разработчика

Для пользования сайтом этот пункт не нужен. Если установлен Node.js, проверки запускаются:

```
node --test tests/core.test.cjs tests/player.test.cjs tests/pages.test.cjs
node --check app.js
node --check player.js
```

Зависимостей npm, сборки и сетевых загрузок нет.
