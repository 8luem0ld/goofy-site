# Проверки локальной версии

Дата: 30 октября 2026 года. Среда автоматических проверок: Windows, Node.js v24.22.1. Сайт запускается без Node.js; эта среда использована только для проверки исходников.

## Выполнено

**36 автоматических проверок прошли.**

```
node --test tests/core.test.cjs tests/player.test.cjs tests/pages.test.cjs
node --check core.js
node --check seed.js
node --check app.js
node --check player.js
```

Проверены:

- Четыре стартовых сериала; поиск на русском, на языке оригинала и по коду; фильтры статуса.
- Повторный импорт без дублей, различение событий озвучки и источника, защита ручных правок.
- Отклонение повреждённого каталога без изменения существующего состояния; отложенные спорные сопоставления и их перенос.
- Запрет удалённых URL, абсолютных путей и выхода за папку сайта.
- Перенос позиции, коллекции и порядка озвучек через JSON; распознавание файлов и спецвыпусков.
- Сборка шаблонов главной, каталога, страницы сериала, коллекции, настроек, редактора, уведомлений и ошибки 404 без исключений; экранирование поискового ввода.
- Логика плеера: восстановление после метаданных, сохранение при паузе и событии времени, неизменный видеоэлемент при переключении рамки, явный выбор для разного монтажа, перенос для совпадающего монтажа, отсчёт и отмена следующей серии, отсутствие незаметной замены источника при ошибке.

Проверки страниц выполнялись с минимальным DOM-адаптером, проверки плеера — с имитацией HTMLMediaElement. Они **не подтверждают** работу кодеков, загрузку видео через `file://`, фактическую раскладку, доступность средствами скринридера или производительность браузера.

## Не выполнено и почему

Инструмент браузерной проверки отклонил локальный адрес `file://` политикой доступа. Ограничение не обходилось. Поэтому скриншоты, инструментальная проверка ширин 360/768/1280/1440 px, фактическое воспроизведение и измерения первого кадра не выполнены.

Видео пользователя в рабочей папке отсутствуют. Реальные серии не скачивались. Приёмка плеера на реальном выпуске остаётся открытой. Полный каталог всех сезонов не собирался из внешних источников, поскольку версия работает автономно.

## Проверка на вашем компьютере

| Сценарий | Действия и ожидаемый результат |
|---|---|
| Автономность | Отключить интернет; открыть `index.html`. Каталог, редактор и локальные видео работают без обращения к сервисам. |
| Запуск видео | Добавить своё поддерживаемое видео и нажать ▶. Зафиксировать браузер, устройство и время первого кадра. |
| Форматы кадра | Открыть свои видео 4:3 и 16:9. Полное изображение видно, свободное место тёмное, растяжения и обрезки нет. |
| Рамка | Во время просмотра отключить рамку. Время и воспроизведение продолжаются. |
| Возобновление | Просмотреть >20 секунд, поставить паузу, обновить страницу. При относительном пути файл открывается снова; для выбранного через диалог файла требуется повторное подключение. Позиция сохранена. |
| Озвучки одного монтажа | Добавить второй файл, задать обоим одну проверенную группу монтажа. Переключение переносит время. |
| Разный монтаж | Очистить группу второго файла. Переключение спрашивает «Продолжить» или «С начала». Отмена оставляет исходную версию. |
| Нет предпочтительной озвучки | Указать отсутствующую студию первой в настройках. Видно сообщение и текущая доступная озвучка; скрытого запуска нет. |
| Ошибка | Указать отсутствующий `media/missing.mp4`. Видна ошибка с повтором и выбором другого источника. |
| Автопереход | Включить настройку; у следующей серии подключить ту же озвучку. После окончания появляется отсчёт 10 секунд. Отмена останавливает переход. |
| Клавиатура | Tab до плеера; пробел, стрелки, M, F. В полях поиска символы вводятся без управления видео. Escape закрывает диалоги и возвращает фокус. |
| Субтитры | Подключить свой WebVTT. Проверить читаемость и отсутствие пересечения с открытой панелью на выбранном размере экрана. |
| Адаптивность | Изменить ширину окна на 360, 768, 1280, 1440 px. Проверить горизонтальную прокрутку, читабельность и доступность кнопок. |
| Импорт и перенос | Импортировать один каталог дважды; количество серий/источников/событий не растёт. Экспортировать JSON и восстановить в другом браузере вместе с теми же видео. |

Сетевые провайдеры, встраиваемые внешние плееры, регистрация и автоматическая синхронизация исключены вашим локальным ограничением; они не помечены как пройденные.
